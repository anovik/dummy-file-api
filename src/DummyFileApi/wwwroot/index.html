Dummy File API

Placeholder files of an exact byte size, in 13 formats — each one a real, openable file, not random bytes. Free, no signup, no API key.

Binary units: 1KB = 1,024 bytes, 1MB = 1,048,576 bytes.

An integer. Varies colors, filler text or the starting row Id, depending on the format.

Using it from code

Same thing without the form — the response is the file itself.

curl -OJ "/api/files/generate?type=pdf&size=1MB"

/api/files/types lists every format with its size bounds. /api/files/history shows your own recent generations.
